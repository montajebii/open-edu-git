# OpenEdu Git Database Migrations

Database migrations for OpenEdu Git using Alembic.

## Setup
1. Install Alembic:
   ```bash
   pip install alembic
   ```
2. Initialize Alembic (if not already done):
   ```bash
   cd backend
   alembic init migrations
   ```

## Creating a Migration
```bash
cd backend
alembic revision --autogenerate -m "description_of_change"
```

## Applying Migrations
```bash
cd backend
alembic upgrade head
```

## Rolling Back
```bash
cd backend
alembic downgrade -1  # Roll back last migration
```

## Notes
- Always review autogenerated migrations before applying.
- Migrations run automatically in Docker Compose via `docker-entrypoint-initdb.d`.
